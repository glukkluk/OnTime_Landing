# OnTime · лендінг

Маркетинговий сайт персонального планувальника OnTime — застосунку для календаря,
завдань і автопланування. Лендінг розповідає про продукт і веде до реєстрації та входу
в Django-застосунок. Контент редагується через адмінку Payload CMS.

## Як запустити

Потрібні Node.js 22.12+ та npm, а також база PostgreSQL у Neon.
CMS і frontend запускаються в окремих терміналах.

### 1. CMS

З кореня проєкту:

```sh
cd cms
npm ci
# Лише якщо .env ще немає:
cp .env.example .env
```

У `cms/.env` задайте:
- `DATABASE_URL` — рядок підключення до Neon.
- `PAYLOAD_SECRET` — довгий випадковий секрет.
- `FRONTEND_URL` — дозволені адреси лендінгу через кому; для локального запуску залиште значення з прикладу.

```sh
npm run dev
```

Адмінка: http://localhost:3000/admin.
Для нової БД створіть адміністратора, сторінку зі slug `home` із заповненими блоками
та заповніть «Налаштування сайту».

### 2. Лендінг

В іншому терміналі з кореня проєкту:

```sh
cd frontend
npm ci
# Лише якщо .env.local ще немає:
cp .env.example .env.local
npm run dev
```

Лендінг: http://localhost:5173 (або адреса, яку виведе Vite).
CMS має залишатися запущеною.

У `frontend/.env.local` змінна `VITE_CMS_URL` задає адресу CMS
(типово `http://localhost:3000`), а `VITE_APP_URL` — адресу Django-застосунку
(типово `http://localhost:8000`). Для роботи входу й реєстрації запустіть Django окремо.
Після зміни цих змінних перезапустіть frontend.
