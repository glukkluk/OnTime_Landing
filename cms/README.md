# OnTime CMS

Адмінка для керування контентом лендінгу OnTime: сторінками, текстами та медіа.
Працює на Payload 3 і Next.js, зберігає дані в PostgreSQL у Neon.

## Як запустити

Потрібні Node.js 22.12+ та npm і база PostgreSQL у Neon.
Виконайте з каталогу `cms/`:

```sh
npm ci
# Лише якщо .env ще немає:
cp .env.example .env
```

У `.env` задайте `DATABASE_URL` із Neon і довгий випадковий `PAYLOAD_SECRET`.
`FRONTEND_URL` містить дозволені адреси лендінгу через кому;
для локального запуску залиште значення з прикладу.

```sh
npm run dev
```

Відкрийте http://localhost:3000/admin.
Для нової БД створіть адміністратора, сторінку зі slug `home` із заповненими блоками
та заповніть «Налаштування сайту».

Запуск самого лендінгу описано в [README проєкту](../README.md).
